
# Proyecto Bases de Datos Avanzadas

**Curso:** TI4601 - Bases de Datos Avanzadas  
**Periodo:** II Semestre 2026  
**Institución:** Tecnológico de Costa Rica

## Descripción

Aplicación web para la administración de promociones y cupones de una tienda departamental, utilizando MongoDB y Redis.

## Tecnologías

- Python 3
- Flask
- MongoDB
- Redis
- HTML, CSS y Bootstrap
- Git y GitHub

## Integrantes

- Arash Mostakhdeminhosseini
- Osvaldo Tames

## Funcionalidades

- Carga inicial de promociones mediante archivos JSON.
- Activación y administración de promociones.
- Consulta de promociones activas.
- Obtención y gestión de cupones.
- Consulta de cupones obtenidos por departamento.
